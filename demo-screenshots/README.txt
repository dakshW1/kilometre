KILOMETRE · DEMO SCREENSHOTS
============================

These are made-up payout screens for the Shark Tank demo. Each one is marked "SAMPLE · not a real payout".

  1-swiggy-orders.png      4 orders. One has no order ID and matches a demo-week order -> shows "Merge / Keep both".
                           One distance is blurred -> shows "AI unsure".
  2-zomato-summary.png     Daily summary screen (total, incentive, tips, login hours, km).
  3-rapido-rides.png       5 bike-taxi rides with pickup and drop areas.
  4-zepto-hindi.png        Screen in Hindi -> shows the AI reads Indian languages.
  5-blinkit-kannada.png    Screen in Kannada.

HOW TO USE ON STAGE
  1. Log in -> Import.
  2. Drag one of these PNGs onto the page (or use the "Try a sample" buttons there).
  3. Add it to the ledger, then drag the SAME file again -> "Already imported" (duplicate protection).

UPDATE THE DATE ON DEMO DAY
  In the gigboss folder run:   npm run samples
  This redraws all five with today's date.

If Gemini is busy, these sample files still get their correct reading automatically (labelled "offline answer").
